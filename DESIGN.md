# Chapterloom interface

- Calm editorial layout: source and detection in narrow left column; chapter list in broad right column.
- Cobalt primary actions, pale blue markers, warm amber review flags, near-white canvas.
- Source artwork displayed when present; abstract waveform cover otherwise.
- Small uppercase step labels clarify workflow. Timecodes use monospaced digits.
- Empty state gives one clear action. Inline chapter controls support name edit, half second nudge, preview, and removal.
- Native SwiftUI controls and sheets preserve macOS keyboard and accessibility behavior.
